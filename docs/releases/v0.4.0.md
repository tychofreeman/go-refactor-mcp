TypeScript, and a round of Go refactorings and fixes.

## Install

```sh
go install github.com/tychofreeman/go-refactor-mcp/cmd/refactor-mcp@v0.4.0
go install github.com/tychofreeman/go-refactor-mcp/cmd/refactor@v0.4.0
claude mcp add --scope user gorefactor -- refactor-mcp
```

## TypeScript

One server serves both languages and routes each call by the file it names. A project without Go gets instructions written for TypeScript.

- The tools Go has, on TypeScript: rename (by member and by local, refusing a member whose name code finds as a string), extract and inline functions and variables (inline_function rewrites early returns into assignments), the signature changes (add, remove, move and introduce parameters, convert parameters to an object, add a result, change a field's or parameter's type), function to method and back, move_method (down to a subclass), move declarations and files, fold (with parameter-object and setter matches), parameterize, merge duplicates, remove dead code, extract an interface, prepare a switch for types and union switch to method, slide statements, invert an if, remove an else.
- Method families: a signature change on a method changes the interface method it implements, the method it overrides, and every other implementation, with the calls through each.
- Edits as Go has them: create and replace files, declarations, statements (with `wrap`), expressions, cases, elements (by `name` and `from`) and fields, stubs for what a test written first uses, and the imports a step's code needs.
- `inspect` for TypeScript, `check` that runs the project's tests (its `test` script, or `node --test`), and `undo`.
- A solution of several tsconfigs, loaded incrementally; errors already in the code are tolerated, and a step must add none.

## Go

- **extract_function**: a string last result carries an early exit as an error does (a refusal: `return nil, "no name"`); returns a captured variable nothing writes again; `split` a case of several values.
- **inline_function**: early returns in ifs, loops and switches become assignments; remove_else's `wrap` is the first step on its own.
- **remove_parameter's `value`** (the inverse of introduce_parameter) and **`also`**; **add_parameter's `replace_variable`**; **move_method** to a struct that embeds the receiver's type; **extract_struct's `into`** an existing struct; add_result splits `return f()`.
- **rename** allows a field that fmt prints, with a note listing the calls whose output changes; extract_struct and remove_dead_code note printing too.
- A getter that makes its result on first use counts as a read; a local a closure only reads is the code's own.
- replace_text: `append`, `function`, matching across spacing; create_file: `overwrite`; `*_file` arguments take content from a file; `refactor list` with arguments; `-version`.
- A call naming a file of another module (or, for TypeScript, another solution) works there.
- Tool descriptions now match the refusals the code makes.
