Fewer refusals on reads and printing, and schemas made from the code that reads them.

## Install

```sh
go install github.com/tychofreeman/go-refactor-mcp/cmd/refactor-mcp@v0.5.0
go install github.com/tychofreeman/go-refactor-mcp/cmd/refactor@v0.5.0
claude mcp add --scope user gorefactor -- refactor-mcp
```

## Go

- **extract_variable's `all_occurrences`** and **inline_variable** with several uses may read through a pointer, an element or a global when nothing between the occurrences changes it: `b.depth*2 + b.depth` extracts and inlines back, as in TypeScript. A write between them, a later iteration of a loop that holds one, or an occurrence in a closure still refuses.
- **rename** of a field printed through a function that passes its arguments on to fmt (a printf wrapper) is a note, as for fmt itself; a wrapper that hands them to anything else still refuses.
- **remove_dead_code's `value`**: a field every literal sets to a path of the struct's other fields goes, its reads becoming that path.

## Both languages

- Tool schemas are made from each tool's arguments struct; every published schema is unchanged.
- Internal: steps of a tool that are not tools of their own, the TypeScript workspace, and walking TypeScript trees are simpler; no change in what the tools do.
