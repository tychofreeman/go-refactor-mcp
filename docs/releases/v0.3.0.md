The first tagged release of gorefactor, an MCP server (and a CLI) that gives Claude type-checked refactorings and edits for Go.

## Install

```sh
go install github.com/tychofreeman/go-refactor-mcp/cmd/refactor-mcp@v0.3.0
go install github.com/tychofreeman/go-refactor-mcp/cmd/refactor@v0.3.0
claude mcp add --scope user gorefactor -- refactor-mcp
```

## What's in it

- **Refactorings** that check what they change with the type checker: rename, extract and inline functions and variables, the signature changes (add, remove, move and introduce parameters, add a result, change a parameter's or field's type), move declarations and files, extract a struct, function to method and back, fold near-duplicates into calls of one function, parameterize, merge duplicate functions, slide statements, invert an if, remove an else, turn a type switch or a type code into methods, and remove dead code. Each step must type-check, and every refusal says why and what to send instead.
- **Edits** for the changes that alter behavior on purpose: add and replace declarations, statements, expressions, cases, elements and fields, replace text in any file, create files, and declare stubs for what a test written first uses.
- **`batch`** runs many steps in one call, with line numbers as they were at the start, references to what earlier steps made, checkpoints, and one undo for the whole batch.
- **`inspect`** reads Go without function bodies, or by name (`names`, `targets`, `uses`).
- **The CLI**, `refactor`, runs any step, a batch, `inspect`, `check` (type-check and, with `run_tests=true`, the tests) and `undo`. Its undo history is kept between invocations, a file per module in the user's cache directory.

See the README for the tools, how to use them well, and the roadmap.
